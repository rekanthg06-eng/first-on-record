Privacy Policy

Last updated: 3 November 2026.

"First on Record" is a private automation used only by its owner. It connects to the owner's own Google account through the YouTube Data API and YouTube Analytics API to (1) upload the owner's videos to the owner's channel and (2) read the channel's own video statistics and comments.

Data accessed

Only data of the owner's own YouTube channel: video metadata, statistics, analytics and public comments on those videos.

Use and storage

This data is used only to improve the owner's own videos. It is stored in a private repository controlled by the owner. It is not sold, shared with third parties or used for advertising. The tool does not collect data from any other user.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.
